# Anonymous visitor analytics

This website uses GoatCounter for privacy-friendly, anonymous visitor statistics.

1. Create a free site at [goatcounter.com](https://www.goatcounter.com/).
2. Copy the site code you choose, such as `my-portfolio`.
3. Open `script.js` and replace `YOUR-GOATCOUNTER-SITE-CODE` with that code.
4. Publish the website, then open `https://YOUR-CODE.goatcounter.com` to view visits and page activity.

The tracker does not collect visitor names, email addresses, or contact form contents.
